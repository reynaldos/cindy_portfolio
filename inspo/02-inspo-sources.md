# 02 — Inspo Sources for Cuts By Cindy

Date: 2026-11-04
Scope: research only. No code. Repo not touched.

## How this was gathered (read first)

- Every URL below was opened in this run with web_fetch.
- The station browser was locked by another run for the whole session. So I could not watch animations or take screenshots.
- "What to steal" is based on: the gallery's own written description, its style/interaction tags, and the live page's text structure. Where I infer a visual, I say "inferred".
- Before build, a designer must open each link in a real browser and confirm the effect.
